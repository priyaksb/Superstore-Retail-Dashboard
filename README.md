Superstore retail data analysis using Excel
# 📊 Data Analytics Dashboard

An interactive **Data Analytics Dashboard** created using **Microsoft Excel, Power Query, Power Pivot, DAX, Pivot Tables, Pivot Charts, Slicers, and Filters**.

This project demonstrates an end-to-end data analytics workflow — from raw data cleaning and transformation to data modeling, business calculations, visualization, and insight generation.

---

## 🎯 Project Objectives

- Clean and transform raw data using **Power Query**
- Build a structured data model using **Power Pivot**
- Create dynamic calculations using **DAX**
- Analyze data using **Pivot Tables and Pivot Charts**
- Build an interactive dashboard using **Slicers and Filters**
- Identify important business trends and patterns
- Convert raw data into meaningful business insights

---

## ❓ Business Questions

The dashboard is designed to answer the following questions:

1. What is the overall sales/revenue performance?
2. What are the total orders and quantities?
3. Which products or categories perform the best?
4. Which regions or locations generate the highest sales?
5. How does sales performance change over time?
6. Which categories contribute the most to total sales?
7. Which products have the highest contribution?
8. Which segments have relatively low performance?
9. What trends and patterns can be identified?
10. How does performance change when different filters are applied?
